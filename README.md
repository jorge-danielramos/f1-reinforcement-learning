# F1 Reinforcement Learning

Selected coursework files exploring Formula 1 pit-stop strategy with a custom environment, masked gradient-bandit action selection, and PyTorch DQN and actor–critic notebooks.

## Status

The notebooks are work in progress and may contain incomplete or invalid cells. Outputs were removed before packaging. No benchmark results or claim of reproducibility is made. Dependency and data setup still need documenting. Third-party FastF1 and MinAtar source copies, data caches, and model binaries are excluded.
